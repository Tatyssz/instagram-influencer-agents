Perfil fictício que representa a faixa B:

| Campo | Detalhe |
|-------|---------|
| **Nome** | Rafaela (“Rafa”), 26 anos |
| **Cidade** | Capital ou grande cidade BR (SP, RJ, BH, Curitiba…) |
| **Seguidores** | 4k – 8k |
| **Nicho** | Beauty — ex.: skincare rotina ou cabelo cacheado |
| **Tipo** | Creator ou UGC; conta Creator/Business no IG |
| **Renda atual** | R$ 0 – 800/mês com marcas (permuta + 1–2 jobs pequenos) |
| **Objetivo** | Fechar **parcerias pagas** recorrentes com marcas beauty |

### Dores (jobs to be done)

1. Media kit amador (Canva genérico ou PDF feio) — marca não leva a sério  
2. Portfólio espalhado (linktree, drive, prints) — difícil mandar “pacote” pro comercial  
3. Grupos de engajamento no Whats/Telegram — barulho, reciprocidade desigual, sensação de bot  
4. Não sabe **precificar** nem o que colocar no kit (métricas, entregáveis)  
5. Crescer sozinha — cansaço, algoritmo, comparação

### O que ela compra no ComJuntas

- Media kit + portfólio **automáticos** a partir do Instagram  
- Relatório IA (“o que melhorar para marcas”)  
- **Comunidade** com regras claras de apoio mútuo (F3+)  
- Cursos avulsos ou no plano (F2) — precificação, pitch, UGC vs creator
