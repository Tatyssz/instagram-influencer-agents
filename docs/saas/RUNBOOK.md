## Cenários comuns

| Problema | Ação |
|----------|------|
| Token IG expirado | Usuária reconecta OAuth no painel |
| Sync falhou | Admin → reprocessar job |
| Sessão engajamento expirada | Usuária → “Autorizar engajamento” de novo |
| Pagamento falhou | Webhook Stripe + e-mail usuária |
| Playwright falhou | Ver log admin; não reexecutar em loop |
